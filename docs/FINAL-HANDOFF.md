# Second Space · MVP 人工验收版

日期：2026-10-22。入口：http://127.0.0.1:5622/ 。旧 5621 保留，不是本次验收入口。

## 启动

在本机双击 `Start-Second-Space.cmd`，或在仓库根目录运行 `./scripts/start-dev.ps1`。校园模型需保持 VPN 连接。启动脚本等待数据库健康检查通过后才显示 Ready。界面右上角切换中英文。

当前：React + FastAPI + Google Cloud SQL PostgreSQL + LangChain/LangGraph。模型只有 campus-qwen。模型输出额度 2048，推理图片缩放至最长边 512，不改变原图；截断明确分类为 ModelOutputTruncated。数据库采用连接池、合并读取与批量事务写入。

## 三条验收路线

1. 卖家：角色入口 → 发布家具 → 正面/俯视/侧面照片及表单 → 上架 → 卖家金额明细。每张图片不超过 15 MiB，HEIC 可上传。可以用演示工具的内置照片快速验证业务；真实上传会调用校园模型。重复角度应拒绝上架，并可修改重提。
2. 买家：发现与推荐 → 最多三个结果及分数 → 家具详情 → 配送表单 → 固定总价确认 → Visa/Mastercard 或 BPAY → 我的订单。按需复制取货/送货物业链接，在另一窗口提交回复；订单页应更新。通过业务模拟窗口检查承运方接受、取货和送达，再由买家确认完好收货。
3. 管理员：经营概览 → 日期查询 → 订单详情 → 资金明细与 Agent 审计 → 冲突处理/政策页面。买家完成验收后，管理员直接看到已结算，卖家和买家看到交易完成。没有待结算、退款或配送受阻状态。

## 建议人工重点检查

- 表单必填星号、空值/数值范围、门宽与门高；楼梯与其他通道使用相同规则。
- 回到上一步后，后续报价/支付信息作废，重新选择后方可下单。
- 中英文切换，尤其是物业回复的时段、电梯、装卸字段。
- 只有送达/验收阶段能确认收货；重复提交不会重复结算。
- 买家时间线显示系统消息，管理员可见 Agent 名称。
- 不同角色之间反复切换，页面可正常加载；两窗口物业确认能同步。
