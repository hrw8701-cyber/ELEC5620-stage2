# 公开二手家具比价

- 点击“获取建议售价”先调用 ListingAgent 校验照片确实为家具且与类别一致，通过才调用 PricingAgent；每次进入新发布业务均为空。
- 修改家具资料不会触发查询或改变已显示数字；会提示重新获取，旧结果不能直接应用到修改后的资料。售价仅由用户编辑或点击“使用参考价格”改变。
- 公开站点只接收目录读取请求，不发送联系方式、地址或照片。校园模型接收名称、类别、材质、成色、年限、尺寸；ListingAgent 同时接收三张主图及额外细节图。
- 校园模型先生成英文检索词和家具子类别，再从 Zirkly 公开类别目录和 Melbourne Used Sofas 公开目录发现候选商品；按检索词排序，每来源最多6个，合计最多12个；每3条一批由模型比对，并限制单条描述长度，顺序处理以避免校园模型并发限制。
- 匿名读取商品网页的 Product JSON-LD，不需要外部账号、API key、登录或验证码。无访问挑战绕过；限定域名、不跟随重定向、每页最多2MB、并发最多3。
- 只接受明确 UsedCondition、InStock、AUD、正数价格的商品。公开挂牌价不等于成交价；不同来源配送条款、地区及零售商溢价可能不同，页面展示来源与限制。
- 模型考虑材料、成色、年限和尺寸，排除不匹配家具、配件和套装；未知参数必须标注且降低匹配分数。不从发布时间推断家具年限。
- 至少3个达到70分的可比商品才计算相似度加权中位数。70分是当前实现的匹配阈值，不是统计置信度。价格只能来自实际抓取结果；模型不能产生金额，返回的虚构ID会被丢弃。
- 获取建议价时读取当前页面，不使用本平台商品均价作为回退，也不读取预置假商品价。外部网站改版、样本不足、模型不可达时，返回明确不可用状态。
- 来源覆盖是上述两个公开站点，不代表已搜索整个互联网。部分品类或参数严格的家具可能没有足够样本。

验证：后端使用隔离数据库；公开网页解析与定价分支有自动测试；frontend/tests/pricing-ui.mjs 使用拦截响应检验按钮和状态，不将模拟结果作为真实估价证明。真实链路的验证结果在交付说明中单独列出。

## 本轮照片门槛

估价前 ListingAgent 只校验家具相关字段及照片，不要求卖家提前填写取货联系人或售价。缺图、非家具、人物/插画、类别不符、照片不可用或模型失败均不进入公开价格查询。最终提交上架仍重新执行完整审核。真实图片必须通过模型；内置演示图片仅按预置家具类别校验，演示标识保留。

## 发现但未修改，待讨论

1. 结构、电气、卫生风险依然主要依赖卖家声明；本轮没有扩展为完整视觉风险识别或安全认证。
2. 买家交付问题和手动解除问题的异常分支仍保留，可能与“不考虑异常”的 MVP 范围冲突。
3. ListingAgent 的审核规则仍主要写在代码及提示词中，M4 政策页不是其动态审核规则来源；没有实现政策变更驱动全部审核标准。
4. 公开样本可能缺少年限、尺寸，且来自不同地区、个人卖家与商家。本轮显式标注未知参数并降低匹配分数，不假设参数相同；是否要求参数完全齐全、仅悉尼同地区、区分商家溢价，需另行讨论。

5. 后端当前所有业务 Agent 共用 graph_lock；较慢的外部比价会使其他需要运行 Agent 的操作等待。这是现有编排并发设计，本轮未改动；拆分锁或改异步任务需单独讨论。
