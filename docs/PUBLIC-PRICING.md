# 公开二手家具比价（2026-10-23 会议版本）

## 数据采集与存储

运行 `.venv/Scripts/python.exe scripts/import-market.py`，匿名读取 Zirkly 和 Melbourne Used Sofas 的公开目录及商品 Product JSON-LD。仅导入明确 UsedCondition、InStock、AUD、正数挂牌价的记录，保存来源链接、原始描述、价格和采集时间到 PostgreSQL `market_reference`。当前已采集35条：沙发12、床6、其他17。

采集限定域名、不跟随重定向、每页最多2MB、并发最多3，不绕过登录或访问挑战。不需要付费API。脚本可重复运行并更新同一来源商品；采集失败保留旧资料。每次刷新由维护者运行脚本，尚未配置定时采集。超过30个真实日的资料不参与估价；重置演示业务不清空市场资料。

## 用户操作和业务链

新发布业务参考价为空。只有点击绿色框内黄色“获取建议售价”按钮，才先执行 ListingAgent 照片/类别审核，再进入 PricingAgent。修改字段不自动查询或改变已有参考价；旧结果不可直接应用到修改后的资料。

真实照片仍由 campus-qwen 审核；演示照片明确走预设类别校验。人物插画、非家具、类别不符等审核失败不进入估价。用户侧图片失败统一为“上传图片不符合平台政策”，管理员保留详细审核原因；最终上架重新完整审核。

PricingAgent 从本地数据库读取公开参考资料，使用可追溯算法，不再让模型逐条联网比较或使用平台商品均价。页面展示公开来源、挂牌价、匹配分、未知参数、调整价格及采集时间。挂牌价不是成交价。

## 估价算法

- 排除类别不符、已知材质不兼容、配件、套装及明显尺寸不符的记录。
- 匹配权重：类型20、材质25、成色20、年限15、尺寸15、名称5。未披露参数列为未知并降低评分，不从发布时间推断年限。
- 最少3条达到55分的记录，最多取前5条。55分为MVP规则阈值，不是统计置信度。
- 仅按来源明确披露的成色和年限作折算，调整系数限制在0.7–1.3；缺失参数不假设相同。
- 按匹配分计算调整价格的加权中位数，以两位小数展示。资料不足返回空价，不生成虚构来源或平台平均价回退。

实测：Fabric sofa / fabric / 良好 / 2年 / 200×90×85cm，通过演示照片类别门槛后，在部署的5623接口返回AUD670，4条真实数据库来源。此案例验证数据与估价链，不作为真实视觉识别准确率证明。

## 发现但未修改，待讨论

1. 结构、电气、卫生风险依然主要依赖卖家声明；本轮没有扩展为完整视觉风险识别或安全认证。
2. 买家交付问题和手动解除问题的异常分支仍保留，可能与“不考虑异常”的 MVP 范围冲突。
3. ListingAgent 的审核规则仍主要写在代码及提示词中，M4 政策页不是其动态审核规则来源；没有实现政策变更驱动全部审核标准。
4. 公开样本可能缺少年限、尺寸，且来自不同地区、个人卖家与商家。本轮显式标注未知参数并降低匹配分数，不假设参数相同；是否要求参数完全齐全、仅悉尼同地区、区分商家溢价，需另行讨论。

5. 后端当前所有业务 Agent 共用 graph_lock；较慢的真实图片审核等模型操作会使其他需要运行 Agent 的操作等待。这是现有编排并发设计，本轮未改动；拆分锁或改异步任务需单独讨论。
